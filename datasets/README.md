# NEXUS Datasets Directory

This directory stores raw repository manifests, extracted dependency trees, and sample benchmarking data:

- `raw/`: Unprocessed repository dumps, raw manifest JSON/XML/YAML files, and external dataset mirrors.
- `processed/`: Normalized dependency graph JSON lines, node/edge export tables, and historical snapshot data.
- `samples/`: Lightweight curated manifests used for local development, unit tests, and CI/CD validation.
